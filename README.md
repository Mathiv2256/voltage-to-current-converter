# Voltage-to-Current Converter Using an Operational Amplifier

## Project overview
A standalone educational website about an op-amp voltage-to-current converter, including a circuit overview, operating principle, equations, worked numerical examples, Multisim simulation interpretation, GATE-style practice questions, interview questions, and interactive quizzes.

## Files
- `index.html` — complete offline website; HTML, CSS, JavaScript, and the Multisim screenshots are embedded in this file.

## Open locally
Open `index.html` in a modern browser such as Google Chrome or Microsoft Edge. No web server or external libraries are required.

## Technical example
For an input voltage of 2 V and an input resistor of 10 kΩ, the ideal current estimate is:

I ≈ Vin / R1 = 2 V / 10 kΩ = 200 μA

The Multisim screenshot displays 199.923 μA. The estimate assumes linear operation with negative feedback and an inverting summing node near 0 V. The estimated output voltage is theoretical, not a voltage measurement from the screenshot.

## Notes
This is an educational simulation resource. Verify the exact circuit wiring, op-amp pin connections, supply limits, and component values against the applicable laboratory instructions and device model.
