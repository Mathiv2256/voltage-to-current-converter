1. Introduction and learning objectives

A voltage-to-current (V–I) converter is a circuit that uses an input voltage to establish a corresponding current. An op-amp and negative feedback can help maintain a predictable voltage at a summing node, so current through a resistor is set by the input voltage and resistor value.

The simulated circuit uses a 2 V DC source, a 10 kΩ input resistor (R1), a 1 kΩ feedback resistor (R2), a virtual op-amp, ±12 V supplies and an ammeter in the feedback branch. The displayed current is 199.923 μA.

Main result for the shown setup:
I ≈ Vin/R1 = 2 V / 10 kΩ = 200 μA

This result assumes the op-amp is operating linearly with negative feedback and its inverting input is held close to 0 V.

Learning objectives

  • Define voltage-to-current conversion and explain the role of negative feedback.
  • Identify the components and trace the current path in the supplied screenshot.
  • Apply Ohm’s law and the ideal op-amp assumptions to calculate current.
  • Estimate the output voltage and compare theoretical and simulated values.
  • Recognize output-swing, load and wiring limitations.
  • Prepare for practical viva, GATE-style questions and core-electronics interviews.

Prerequisites

Ohm’s law, current direction, resistor voltage drops, op-amp inverting/non-inverting terminals, negative feedback, virtual ground and DC supply polarity.

3. Working principle — step by step

  1. Input is applied: V1 supplies +2 V through R1 = 10 kΩ to the inverting input node.
  2. Non-inverting input is grounded: V+ = 0 V.
  3. Negative feedback acts: while the op-amp remains linear and feedback is negative, the op-amp drives its output so V− is approximately equal to V+. Therefore the summing node is approximately 0 V (a virtual ground).
  4. Current through R1: the voltage across R1 is close to 2 V, so IR1 ≈ 2 V/10 kΩ = 200 μA.
  5. Current through the feedback branch: ideal op-amp input current is approximately zero, so almost all current arriving at the summing node flows through R2 and the series meter. The ammeter therefore displays approximately the same current.
  6. Output voltage adjusts: for R2 = 1 kΩ, about 200 μA causes a 0.2 V drop across R2. With the summing node at about 0 V, the output is approximately −0.2 V.
Ideal op-amp assumptions used: (1) input currents are approximately zero, (2) negative feedback with linear operation makes V+ ≈ V−, and (3) the output can move to the voltage needed to satisfy feedback. These approximations are valid only within the device's input, output and bandwidth limits.

DC and varying-input behaviour

DC input: the current is approximately constant and proportional to the applied DC voltage.

Slowly varying input: the current follows the input approximately as I(t) ≈ Vin(t)/R1, provided the op-amp has sufficient bandwidth and the output remains within its allowed range.

Sign: reversing input polarity reverses current direction in the ideal model. In the shown inverting configuration, output voltage has the opposite sign to the input.

Advantages and limitations

Advantages

  • Simple and easy to analyse with Ohm's law.
  • Negative feedback improves the virtual-ground condition.
  • Input voltage controls the branch current predictably within the linear range.

Limitations

  • Output swing and output current are finite.
  • Resistor tolerance changes the current slightly.
  • Op-amp offset, bias current and finite gain create small errors.
  • The exact screenshot measures feedback-branch current; it does not by itself demonstrate current regulation into an independent external load.

4. Equations, assumptions and derivation

Step 1 — Input resistor current

Let Vn be the voltage at the inverting summing node. By Ohm’s law:

IR1 = (Vin − Vn)/R1

With negative feedback and a grounded non-inverting input, the ideal linear op-amp approximation gives Vn ≈ 0 V. Therefore:

IR1 ≈ Vin/R1

Step 2 — Feedback current

An ideal op-amp draws negligible current into its input pin. By Kirchhoff’s Current Law at the summing node, the resistor current must flow through the feedback branch:

Imeter ≈ IR2 ≈ IR1 ≈ Vin/R1

Step 3 — Output voltage

For an ideal inverting stage with R2 in the feedback path, the output voltage is:

Vout ≈ −(R2/R1) Vin

Equivalently, using the current through R2:

Vout ≈ −IR2R2

Here the negative sign indicates inversion. The current meter’s internal resistance is assumed small compared with R2; if it is not negligible, include it in the feedback resistance when estimating the output voltage.

Current conversion factor

For R1 = 10 kΩ, 1/R1 = 0.0001 S = 100 μA/V. Thus a 2 V input gives about 200 μA, so long as the assumed linear operating conditions hold.

Boundary conditions: these relationships fail if the op-amp saturates, feedback is open or wired with the wrong polarity, the input common-mode range is violated, or the meter/load alters the feedback branch substantially.

5. Three solved numerical examples

Example 1 — Find current for the supplied values (basic)

Given: Vin = 2 V, R1 = 10 kΩ. Find: current.

Formula: I ≈ Vin/R1.

I = 2 V / 10,000 Ω = 0.0002 A = 200 μA

Answer: 200 μA. This is the ideal current estimate when the summing node is near 0 V.

Example 2 — Choose R1 for a desired current (moderate)

Given: Vin = 2.5 V and target current I = 250 μA. Find: R1.

Rearrange I = V/R to obtain R1 = Vin/I.

R1 = 2.5 V / 250 × 10−6 A = 10,000 Ω = 10 kΩ

Answer: choose R1 = 10 kΩ (ideal value). Select a suitable tolerance rating for a practical circuit.

Example 3 — Calculate output voltage and compare simulation (GATE-style)

Given: Vin = 2 V, R1 = 10 kΩ, R2 = 1 kΩ. The summing node is approximately 0 V. Find: I and Vout.

I ≈ 2/10,000 = 200 μA
Vout ≈ −IR2 = −(200 μA)(1 kΩ) = −0.2 V

The screenshot meter shows 199.923 μA. Using that reading, |Vout| is approximately (199.923 μA)(1 kΩ) = 0.199923 V, so Vout is approximately −0.199923 V for the idealised orientation.

Answer: I ≈ 200 μA and Vout ≈ −0.2 V. The actual value may differ slightly due to the op-amp model and meter resistance.

Useful calculation shortcuts

  • 2 V across 10 kΩ → 0.2 mA → 200 μA.
  • For a chosen current, R = V/I.
  • In this feedback configuration, output magnitude scales as |Vout| = I × R2.
  • Keep units consistent: kΩ = 10³ Ω; mA = 10⁻³ A; μA = 10⁻⁶ A.

Suggested check sequence in Multisim

  1. Confirm V1 is a 2 V DC source referenced to the circuit ground.
  2. Verify R1 = 10 kΩ and R2 = 1 kΩ by opening each component's properties.
  3. Confirm the non-inverting (+) input is grounded and the input resistor reaches the inverting (−) node.
  4. Confirm the feedback path connects the output back to the summing node through R2 and the current meter.
  5. Check +12 V and −12 V supply pin connections for the selected op-amp model.
  6. Set the multimeter to DC current mode and connect it in series with the branch under measurement.
  7. Run the simulation. If the result is unexpected, stop the simulation, inspect connection junctions, then run it again.

Common mistakes

  • Putting the ammeter in parallel rather than series.
  • Leaving an op-amp supply pin unpowered or reversing supply polarity.
  • Using a ground symbol that is not actually connected to the intended reference node.
  • Confusing mA with μA; 200 μA = 0.2 mA.
  • Assuming the calculated output voltage was measured even though only current is shown in the screenshot.

8. Core electronics company interview and viva questions

1. What is a voltage-to-current converter?

A circuit in which an input voltage establishes a proportional output current. Op-amp feedback can improve control of the voltage across a current-setting resistor.

2. What is the current for 2 V across 10 kΩ?

I = V/R = 2/10,000 A = 0.0002 A = 200 μA, assuming the resistor has approximately 2 V across it.

3. Why is the inverting input called a virtual ground here?

The non-inverting input is grounded. Negative feedback drives the output so the inverting input is nearly the same voltage, about 0 V, without a direct ground connection at that node.

4. What does the op-amp contribute?

It changes the output voltage to maintain the feedback condition. It does not set the current alone; the input voltage and current-setting resistor determine the ideal current.

5. What is the role of R1?

R1 converts the input voltage into a current: I ≈ Vin/R1 when the summing node is near 0 V.

6. What is the role of R2?

R2 is the feedback resistor in the supplied circuit. It helps set the output voltage needed to sustain the current: Vout ≈ −I R2.

7. Why does Multisim show 199.923 μA rather than 200 μA?

The ideal calculation assumes an exact virtual ground and ideal components. A simulated op-amp model, finite input/output behaviour and meter resistance/numerical precision can produce a small difference.

8. What is negative feedback?

A portion of the output is returned to the input in a way that reduces the difference between the op-amp input voltages. It normally improves predictable linear operation when correctly connected.

9. Why is an ammeter connected in series?

The branch current must flow through the ammeter for it to measure current. A current meter placed in parallel can create a near-short circuit and an invalid result.

10. What can cause op-amp saturation?

Demanding an output outside its available voltage swing, incorrect supply connections, wrong feedback polarity, or an input outside the permitted common-mode range.

11. What changes when R1 is doubled?

At the same input voltage and under the same ideal assumptions, current halves because I is inversely proportional to R1.

12. What changes when R2 is doubled?

The ideal current remains approximately set by Vin/R1, while the required output voltage magnitude doubles. The circuit can leave its linear operating range if too much output voltage is required.

13. How can the circuit be verified experimentally?

Calculate I = Vin/R1, measure the current in series with the feedback path, confirm the output voltage if a voltage probe is available, and compare theory with simulation.

14. Is the current in this screenshot demonstrated through an independent load?

No independent load is clearly shown. The meter is in the feedback branch. Therefore, the screenshot verifies that branch current; it does not by itself verify load-independent current regulation through an arbitrary load.

15. What are practical non-idealities?

Input offset voltage, bias current, finite open-loop gain, finite output current, output swing, bandwidth, slew rate and resistor tolerance.

Industry perspective

Voltage-controlled current circuits are used in sensor excitation, transconductance stages, current-loop interfaces, test equipment and actuator drivers. Practical designs require consideration of load range, current direction, compliance voltage, output capability, stability, accuracy and component tolerances. The exact screenshot is a teaching feedback-current example; product designs may use a dedicated load-driving V–I topology.

9. Applications and practical design considerations

Where the concept is used

  • Voltage-controlled current sources for sensors and test setups.
  • Transconductance stages in analog signal processing.
  • Current-loop and actuator interface circuits when designed for the intended load.
  • Laboratory demonstrations of op-amp feedback and current measurement.
  • Analog electronics design, hardware testing and validation.

What engineers check

  • Required current range and current direction.
  • Load resistance and voltage headroom (compliance).
  • Op-amp output swing, output-current rating and supply range.
  • Resistor tolerance and temperature coefficient.
  • Offset, noise, bandwidth, stability and measurement loading.

Key definitions

  • Negative feedback: output is returned in a way that opposes the input difference.
  • Virtual ground: a node held near 0 V by feedback, not a direct ground connection.
  • Transconductance: ratio of output current to input voltage, in siemens (S).
  • Output compliance: output-voltage range available to sustain the desired current.

High-priority exam points

  • Convert kΩ to Ω before calculating current.
  • Remember 200 μA = 0.2 mA = 0.0002 A.
  • In the shown topology the ideal current depends mainly on Vin and R1; R2 mainly sets required output voltage.
  • At saturation, the virtual-ground assumption is no longer valid.
  • Do not describe a calculated value as a measured value. The simulation screenshot displays current rather than output voltage.

Fast troubleshooting checklist

Check supply rails, common ground, op-amp pin polarity, negative-feedback path, resistor values, meter mode and series connection, source magnitude/polarity, and whether the op-amp output is saturated.
